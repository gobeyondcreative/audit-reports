HighNo active paid acquisition

Opportunity: Do not launch paid media simply to fill a scorecard. Validate economics first, then test Google Search or Local Services Ads against incremental booked calls and gross profit.

HighLocal SEO heatmap coverage is only 46%

The #5 sampled rank is good, but the broader map grid shows uneven visibility.

Fix: Track the same geo grid monthly, strengthen location relevance, improve citation consistency, and measure movement into top-three cells.

HighListings accuracy tops out at 60%

Ten sources produced no match and six more were only partial matches.

Fix: Build a canonical NAP record and clean high-authority sources first. Re-run the listing audit after each cleanup wave.

Medium Priority

MediumReview-response speed is slow

The app shows 88% reply coverage, which is strong, but an average response time of 30+ days.

Fix: Keep the high reply percentage and reduce the response SLA to 24 to 72 hours.

MediumInstalled ad tags can create false campaign signals

Google Ads and Meta tracking code is present even though campaigns are not active. Automated auditing can mistake instrumentation for media activity.

Fix: Treat campaign detection and tag detection as separate audit fields. Active spend should require an advertiser or account-level signal, not merely a pixel.
